Protección del trabajo offline

Pendiente de comprobación

Solicita persistencia cuando vayas a guardar expedientes importantes. No cifra los datos.

¿Por qué puede denegarse?

El navegador decide si concede persistencia; la PWA no puede forzarla. En Chrome y otros navegadores Chromium, la instalación y el uso habitual pueden ayudar, pero no garantizan el permiso. Firefox puede solicitar confirmación o aplicar permisos del sitio.

La denegación no significa que el modo offline haya fallado. Conserva copias JSON protegidas fuera del navegador: incluso con persistencia, el usuario puede borrar los datos.

RabbitMole en tu dispositivo

Instalación y funcionamiento sin conexión
  1. ▣Chrome, Edge o Brave: utiliza «Instalar RabbitMole» en el menú del navegador y abre desde su icono.
  2. ◧iPhone y iPad: desde Safari pulsa Compartir → Añadir a pantalla de inicio y habilita «Abrir como app web» cuando aparezca.
  3. ✓Antes de desconectarte: abre la PWA y pulsa Comprobar en «Protección del trabajo offline». Espera a que la caché esté completa.
  4. ✈Prueba en modo avión: cierra todas las ventanas, desconecta Internet y vuelve a abrir desde el icono. Conserva copias JSON cifradas o protegidas fuera del navegador.

La instalación depende del navegador y del sistema. Si no admite PWA, puedes usar la web limitada o un navegador compatible. La instalación no otorga permisos del sistema ni sustituye la autorización de los servicios externos.

Preparar terminal y Discovery: Android / iPhone / iPad

La terminal es opcional. RabbitMole no ejecuta comandos del sistema, y la preparación de este apartado no realiza reconocimiento de red ni envía datos. Úsala solo con el alcance y los permisos autorizados.

Android · instalar y preparar Termux
  1. Instala Termux desde F-Droid o desde las versiones oficiales en GitHub. Mantén todas las extensiones de Termux en la misma fuente de firma. No es una aplicación para iOS.
  2. Abre Termux con conexión y prepara Python y Git. Nmap es opcional. Solo concede acceso a los archivos compartidos si vas a transferir el JSON mediante Descargas.
pkg update
pkg upgrade
pkg install python git nmap
termux-setup-storage
git clone --depth 1 https://github.com/sempitern0/RabbitMole.git
cd RabbitMole
python discovery/discover.py doctor

El repositorio sin indicar rama utiliza main (versión publicada del código, que puede diferir de esta PR). Si necesitas probar esta PR antes del merge, clona con --branch feature/pwa-version-offline-fallback-20261018.

Tras recibir autorización expresa para una subred IPv4 privada, puedes ejecutar el asistente:

python discovery/discover.py wizard

Introduce el CIDR aprobado, elige un motor disponible y guarda un archivo .json nuevo, por ejemplo en ~/storage/downloads/; el asistente requiere escribir AUTORIZO antes de descubrir hosts. Abre RabbitMole → Hardware → Captura asistida; revisa e incorpora las filas. Repite con el mismo archivo en Redes → Captura asistida.

Android puede bloquear Nmap, ICMP o la detección de interfaces sin root. No eludas las restricciones del dispositivo. Las capturas en Descargas son potencialmente sensibles: muévelas a almacenamiento protegido y aplica la política de retención autorizada. Si no funciona, registra observaciones manualmente.

iPhone / iPad · alternativa sin Termux

Termux no existe para iOS/iPadOS. Para tareas locales auxiliares puedes utilizar a-Shell (terminal y Python) o iSH (entorno Linux emulado), instaladas desde sus canales oficiales. No equivalen a Termux ni garantizan que Discovery pueda acceder a la red del dispositivo.

En a-Shell, comprueba las utilidades disponibles sin realizar reconocimiento:

help -l
python3 --version

Para descubrir hosts, utiliza Discovery en un PC autorizado y transfiere su JSON mediante un canal aprobado a la app Archivos del iPhone/iPad. Después, importa el archivo desde Hardware → Captura asistida y Redes → Captura asistida. También existe un puente HTTPS LAN opcional si el navegador, el certificado y las políticas locales lo permiten.

En iOS, las apps están aisladas entre sí: utiliza Archivos o el selector del sistema. Si una app solicita permiso de red local, revísalo en Ajustes → Privacidad y seguridad → Red local. No presupongas soporte de sockets, Nmap, ICMP o escaneo de redes desde una terminal iOS.

Prueba final: con datos ficticios, verifica que la terminal puede producir o recibir el JSON, que RabbitMole permite revisarlo sin sobrescritura automática y que el expediente sigue abriendo sin conexión. Las funciones de Discovery no convierten respuestas de hosts en vulnerabilidades o VLAN comprobadas.
